OUR LITTLE WORLD — QUICK START

1. Open index.html in a browser to preview the website.
2. Personalise the text:
   - Replace YOUR NAME and HER NAME.
   - Edit the story dates and descriptions.
   - Edit the letter sign-off and message.
3. Add photos:
   - In index.html, find <div class="photo"><span>Add photo 1</span></div>
   - Replace that whole div with:
     <div class="photo"><img src="photo1.jpg" alt="Our memory"></div>
   - Upload photo1.jpg (and other images) into the same folder as index.html.
4. Add music (optional):
   - Put a legally usable MP3 named song.mp3 in this folder.
   - In index.html, find <audio id="music" loop></audio>
   - Change it to <audio id="music" loop src="song.mp3"></audio>
   - Use music you own or have permission to share.
5. Publish free with GitHub Pages:
   - Create/sign in to github.com on your phone.
   - Create a new public repository, e.g. our-little-world.
   - Upload index.html and any photo/music files.
   - Open repository Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Choose main and /(root), then Save.
   - Wait a minute or two. Your website link will look like:
     https://YOUR-USERNAME.github.io/our-little-world/

PHONE TIP:
On Android, use Chrome and GitHub's website. If file upload controls are hard to find,
turn on Chrome's Desktop site from the three-dot menu.

This is a starter template. The photos, names, dates and text are placeholders until you personalise them.
